This project implements a Federated Learning (FL) framework for heart disease prediction using the Framingham Heart Study dataset.
The goal is to build a privacy-preserving model that allows multiple clients to train collaboratively without sharing their raw medical data.

Project Overview

Implemented Federated Averaging (FedAvg) and FedAdam optimizers.

Designed a Hybrid FL model using Deep Neural Networks (DNN).

Evaluated performance across multiple client devices.

Applied feature selection, regularization, and hyperparameter tuning to improve accuracy.

Achieved ~80% global accuracy, with ongoing optimization toward 90%.

Built using TensorFlow Federated (TFF).
